TypeBuffer

Masked typing mode for your desktop. Type freely, auto-correct grammar, and dump the text in one go.

Download Latest Release View on GitHub

How it works

TypeBuffer intercepts your keyboard input silently. Nothing appears on your screen as you type. Once you stop typing for 1.5 seconds, TypeBuffer automatically flushes the text you typed into your active window. Instant passthrough ensures that shortcuts (Ctrl+C, Ctrl+V), arrow keys, and system keys work flawlessly without any delay.

🔒 Ghost Typing

Hide your typing process. Think, pause, and let your complete sentence appear at once.

✨ Auto Spellchecker

Integrated with LanguageTool and OpenAI. It checks the grammar of your complete sentence before sending it to the app.

🚀 Run at Startup

Includes a cross-platform autostart script. Set it up once and forget about it. Perfect for daily workflows.

💻 Cross-Platform

Native low-level hooks on Windows for perfect shortcut passthrough, with pynput support for macOS and Linux.

Getting Started

$ pip install -r requirements.txt
$ python TypeBuffer.py

2026-09-10 18:00:00 MASKED MODE (timeout=1.5s). ESC to exit.
2026-09-10 18:00:00 Instant pass-through: arrows, Caps Lock, Ctrl+C/V, Alt, Win, Del, F-keys...

Enable Auto-Start

Set up TypeBuffer to run automatically when you log into your system:

$ python setup_autostart.py --install
